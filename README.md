# media de clientes

Repositorio de imágenes y vídeos que se programan en GHL (se sirven por URL pública raw).

Estructura: `<cliente>/AAAA-MM/AAAA-MM-DD_plataformas_tema.ext`

- `zynel/` – Zynel
- `mayte/` – Centro Dental Mayte Montesinos

URL: `https://raw.githubusercontent.com/carlosbarrajoncatalan/zynel-media/main/<cliente>/AAAA-MM/<archivo>`

No mover ni renombrar archivos que estén en publicaciones programadas o borradores sin actualizar antes la URL en GHL.
